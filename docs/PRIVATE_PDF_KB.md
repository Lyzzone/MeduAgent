# 私有 PDF 知识库实现

## 用途与数据边界

本模块供本机验证长篇 PDF 的解析、索引和问答检索。输入 PDF、SHA-256 清单和派生 SQLite 索引保存在 Git 忽略的 `data/` 下。公开课程教程仍保存在 `corpus/freecodecamp_zh/`，构建为独立的公开索引。未确认再分发许可的 PDF 不进入 GitHub 仓库、公开网站或外部模型请求。

## 数据流

1. `import-private-pdf` 流式计算源文件 SHA-256，复制到 `data/private_corpus/pdfs/` 并复核副本哈希，最后原子写入 `manifest.json`。
2. `ingest-private-pdf` 复核清单和文件哈希。PyMuPDF 逐页提取文字层，按每页最多约 1000 字符切块，每个片段记录 `document_id`、标题、页码、片段 ID 和原文。索引在临时文件中构建，成功后替换旧版数据库。
3. SQLite FTS5 对标题、页码标签和正文分词。`ask-private` 经过 LangGraph 检索/拒答/引用校验流程，只使用本地摘录生成器。
4. API 在就绪检查及问答端点复核索引的 `visibility` 元数据，拒绝私有索引。

公开和私有索引使用相同的检索接口与引用数据模型；私有来源的 `source_url` 留空，`page` 记录 PDF 的 1 起始页号。网页只会给 HTTPS 来源显示外链。

## 当前限制

- 只处理文字层。零文本页、极少文本页会在入库统计中列出；图片、复杂公式和表格未经过 OCR 或结构化理解。
- 仅有词项检索，尚未加入向量召回、重排、独立标注集或高并发性能测试。
- 摘录式预览可核对原文位置，但不等于大模型对整份 PDF 的推理或可靠答案。
- 来源 PDF 的知识可能过时或含错误；面试题答案应另用权威来源复核。

## 验证

运行 `python -m pytest -q`。合成 PDF 测试覆盖逐页引用、零文本页、哈希篡改、HTTP 阻断和外部生成器阻断。实际 PDF 入库后需要抽查命中片段的标题、页码与 PDF 原页是否一致；这些抽查结果只记录在本地学习笔记中。
